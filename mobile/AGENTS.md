# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v56.0.0/ before writing any code.

# Coding Rules

  - Break files into small, focused components as much as possible
  - Never use inline styles — use StyleSheet.create() in the same file as the component
  - Keep files small and readable; extract logic into hooks and sub-components
  - Import hooks directly (useEffect, useState, useMemo, useCallback) from 'react' — never use React.useEffect, React.useState, etc.
